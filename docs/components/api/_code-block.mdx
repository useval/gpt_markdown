### `CodeBlockStyle`

How a fenced code block is drawn.

Set it as `GptMarkdownStyleSheet(codeBlock: CodeBlockStyle(…))` on the widget, or in `GptMarkdownThemeData` for the whole app. Every field is optional; an unset one falls back to the theme, then to the default.

| Field | Type | Description |
|---|---|---|
| `highlightWhileStreaming` | `bool?` | Whether to highlight an unfinished fence on every source update. Defaults to true for compatibility. False renders plain code until the closing fence arrives, avoiding repeated highlighting of large blocks. |
| `backgroundColor` | `Color?` | Panel fill. Defaults to `ColorScheme.surfaceContainer`. |
| `borderColor` | `Color?` | Panel outline. Defaults to `ColorScheme.outlineVariant`. |
| `borderWidth` | `double?` | Outline thickness. Defaults to 1 when a colour is set. |
| `borderRadius` | `Radius?` | Corner rounding. Defaults to 12. |
| `padding` | `EdgeInsetsGeometry?` | Space around the code. Defaults to 16, with a tighter top inset. |
| `headerPadding` | `EdgeInsetsGeometry?` | Space around the header row. |
| `fontFamily` | `String?` | Code font. Defaults to the bundled JetBrains Mono. |
| `fontFamilyPackage` | `String?` | Package the font ships in. |
| `fontSize` | `double?` | Code size. Defaults to the surrounding size. |
| `textColor` | `Color?` | Code colour. Defaults to the surrounding colour. |
| `showLanguageLabel` | `bool?` | Whether the language is shown. Defaults to true. |
| `languageStyle` | `TextStyle?` | Style of that label. |
| `showCopyButton` | `bool?` | Whether the copy button is shown. Defaults to true. |
| `copyLabel` | `String?` | Accessible copy-button tooltip. Defaults to `Copy code`. |
| `copiedLabel` | `String?` | Accessible copy-button tooltip after copying. Defaults to `Copied!`. |

| Member | Type | Description |
|---|---|---|
| `merge(CodeBlockStyle? other)` | `CodeBlockStyle` | This style, with any unset field taken from `other`, field by field. |
| `resolve(ColorScheme scheme)` | `CodeBlockStyle` | This style with every remaining default filled in. |
| `copyWith({…})` | `CodeBlockStyle` | A copy with the given fields replaced. |
| `static lerp(CodeBlockStyle? a, CodeBlockStyle? b, double t)` | `CodeBlockStyle?` | Linearly interpolates between two styles. |
