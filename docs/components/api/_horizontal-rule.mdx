### `HrStyle`

How a horizontal rule is drawn.

Set it as `GptMarkdownStyleSheet(hr: HrStyle(…))` on the widget, or in `GptMarkdownThemeData` for the whole app. Every field is optional; an unset one falls back to the theme, then to the default.

| Field | Type | Description |
|---|---|---|
| `thickness` | `double?` | Line thickness. Defaults to the theme's `hrLineThickness`. |
| `color` | `Color?` | Line colour. Defaults to the theme's `hrLineColor`. |
| `padding` | `EdgeInsetsGeometry?` | Space around the line. Defaults to `hrLinePadding`. |

| Member | Type | Description |
|---|---|---|
| `merge(HrStyle? other)` | `HrStyle` | This style, with any unset field taken from `other`, field by field. |
| `resolve(ColorScheme scheme)` | `HrStyle` | This style with every remaining default filled in. |
| `copyWith({…})` | `HrStyle` | A copy with the given fields replaced. |
| `static lerp(HrStyle? a, HrStyle? b, double t)` | `HrStyle?` | Linearly interpolates between two styles. |

<details>
<summary><code>resolve</code>: more</summary>

Falls back to the `hrLine*` fields on `GptMarkdownThemeData`, which remain
the app-wide way to set them.

</details>
