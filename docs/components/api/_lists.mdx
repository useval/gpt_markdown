### `ListStyle`

How ordered and unordered list items are drawn.

Set it as `GptMarkdownStyleSheet(list: ListStyle(…))` on the widget, or in `GptMarkdownThemeData` for the whole app. Every field is optional; an unset one falls back to the theme, then to the default.

| Field | Type | Description |
|---|---|---|
| `bulletSize` | `double?` | Bullet diameter. Defaults to 0.3x the font size. |
| `bulletColor` | `Color?` | Bullet colour. Defaults to the text colour. |
| `bulletShape` | `BoxShape?` | Bullet shape. Defaults to a circle. |
| `markerTextStyle` | `TextStyle?` | Style of the `1.` marker. Defaults to weight 100. |
| `indent` | `double?` | Space before the marker. Defaults to the value each list kind already used — 7 for bullets, 6 for numbers. |
| `gapAfterMarker` | `double?` | Space between marker and text. Defaults to the value each list kind already used — 10 for bullets, 6 for numbers. |

| Member | Type | Description |
|---|---|---|
| `merge(ListStyle? other)` | `ListStyle` | This style, with any unset field taken from `other`, field by field. |
| `resolve(ColorScheme scheme)` | `ListStyle` | This style with every remaining default filled in. |
| `copyWith({…})` | `ListStyle` | A copy with the given fields replaced. |
| `static lerp(ListStyle? a, ListStyle? b, double t)` | `ListStyle?` | Linearly interpolates between two styles. |

<details>
<summary><code>resolve</code>: more</summary>

Bullet size and colour depend on the surrounding text, so they stay null
here and are computed per item unless set.

</details>
