### `LatexStyle`

How rendered maths is drawn.

Set it as `GptMarkdownStyleSheet(latex: LatexStyle(…))` on the widget, or in `GptMarkdownThemeData` for the whole app. Every field is optional; an unset one falls back to the theme, then to the default.

| Field | Type | Description |
|---|---|---|
| `textStyle` | `TextStyle?` | Applied on top of the surrounding style. |
| `padding` | `EdgeInsetsGeometry?` | Space around block maths. Defaults to none. |
| `backgroundColor` | `Color?` | Fill behind block maths. Defaults to none. |
| `borderRadius` | `Radius?` | Corner rounding of that fill. |
| `scrollBlockHorizontally` | `bool?` | Whether block maths scrolls sideways rather than overflowing. Defaults to false. |

| Member | Type | Description |
|---|---|---|
| `merge(LatexStyle? other)` | `LatexStyle` | This style, with any unset field taken from `other`, field by field. |
| `resolve(ColorScheme scheme)` | `LatexStyle` | This style with every remaining default filled in. |
| `copyWith({…})` | `LatexStyle` | A copy with the given fields replaced. |
| `static lerp(LatexStyle? a, LatexStyle? b, double t)` | `LatexStyle?` | Linearly interpolates between two styles. |

### `inlineLatexBuilder`

Builds the span for an inline formula — `\(…\)`, or `$…$` with
`useDollarSignsForLatex` — replacing the default one.

Wins over `latexBuilder` for inline maths when both are set. See
`InlineLatexBuilder`.

```dart
typedef InlineLatexBuilder = InlineSpan Function(
  InlineLatexBuildDetails details,
);
```

### `blockLatexBuilder`

Builds the widget for a block formula — `\[…\]`, or `$$…$$` with
`useDollarSignsForLatex` — replacing the default one.

Wins over `latexBuilder` for block maths when both are set.
`LatexStyle`'s padding, background and horizontal scroll are applied
around the result. See `BlockLatexBuilder`.

```dart
typedef BlockLatexBuilder = Widget Function(BlockLatexBuildDetails details);
```

### `onLatexTap`

Called when a formula is tapped, with the formula and the part of it
under the finger — see `LatexTapDetails`.

```dart
GptMarkdown(
  reply,
  onLatexTap: (tap) => showFormula(context, tap.source),
)
```

The default formulas wire it, as do the builders' `defaultSpan` and
`defaultWidget`. The deprecated `latexBuilder` does not.

```dart
void Function(LatexTapDetails details)? onLatexTap
```

### `useDollarSignsForLatex`

Whether to use dollar signs for LaTeX.

```dart
bool useDollarSignsForLatex
```

### `latexWorkaround`

The LaTeX workaround.

```dart
String Function(String tex)? latexWorkaround
```

### `latexBuilder`

:::caution[Deprecated]
Deprecated.
:::

Builds every formula, inline and block, as a widget.

Used only where `inlineLatexBuilder` or `blockLatexBuilder` is null. An
inline result is wrapped in a `WidgetSpan` by the package.

```dart
typedef LatexBuilder = Widget Function(
  BuildContext context,
  String tex,
  TextStyle textStyle,
  bool inline,
);
```

### `InlineLatexBuildDetails`

What `InlineLatexBuilder` is told about one inline formula.

| Member | Type | Description |
|---|---|---|
| `context` | `BuildContext` | The element this construct is being built in. |
| `config` | `GptMarkdownConfig` | The configuration in force at this point in the document. |
| `style` | `TextStyle` | The text style in effect for this construct, fully resolved. |
| `tex` | `String` | The formula to render, after `GptMarkdownConfig.latexWorkaround`. |
| `source` | `String` | The formula as written in the document, before any workaround. |
| `onTap` | `VoidCallback?` | Invokes `GptMarkdownConfig.onLatexTap` for this formula as a whole, or null when no handler is set. |
| `defaultSpan()` | `InlineSpan` | Exactly what the formula renders as when no builder is given, taps included. Returning it is a no-op, so it is the place to start. |
| `defaultWidget()` | `Widget` | The default formula as a widget, not yet placed in the line — to wrap in something of your own and hand to `asWidgetSpan`. |
| `asWidgetSpan(Widget child)` | `InlineSpan` | `child` placed in the line exactly the way the default formula is: aligned on the text baseline, and scaled with the paragraph around it. |

<details>
<summary><code>config</code>: more</summary>

Read `GptMarkdownConfig.scope` from it to tell a link in a table cell
from one in ordinary content, and `GptMarkdownConfig.textDirection` or
`GptMarkdownConfig.textScaler` when a widget of your own needs them.
`TableBuilder` and `OrderedListBuilder` already take a whole config for
the same reason.

</details>

<details>
<summary><code>style</code>: more</summary>

A builder never has to guess a default: this is what the construct would
have been drawn with, its own style already applied over the surrounding
one.

</details>

<details>
<summary><code>onTap</code>: more</summary>

`defaultSpan` already wires the handler, and reports which part of the
formula was tapped. Call this from a formula of your own, rather than
`onLatexTap` directly, so the details stay right when they change.

</details>

<details>
<summary><code>asWidgetSpan</code>: more</summary>

`onTap` is not attached: a formula widget usually handles its own taps.

</details>

### `LatexTapDetails`

What `GptMarkdownConfig.onLatexTap` is told about a tap on a formula.

| Member | Type | Description |
|---|---|---|
| `tex` | `String` | The whole formula as rendered, after `GptMarkdownConfig.latexWorkaround`. |
| `source` | `String` | The whole formula as written in the document, before any workaround. |
| `inline` | `bool` | Whether the formula is inline (`\(…\)`, `$…$`) rather than a block (`\[…\]`, `$$…$$`). |
| `tappedTex` | `String?` | The TeX of the part under the finger — a symbol, a fraction, a group — or null when the tap did not land on a part, or the builder that drew the formula only reports the formula as a whole. |
| `href` | `String?` | The target of an `\href{…}{…}` the tap landed on, or null. |
