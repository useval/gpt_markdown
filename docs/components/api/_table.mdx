### `TableStyle`

How a table is drawn.

Set it as `GptMarkdownStyleSheet(table: TableStyle(…))` on the widget, or in `GptMarkdownThemeData` for the whole app. Every field is optional; an unset one falls back to the theme, then to the default.

| Field | Type | Description |
|---|---|---|
| `borderColor` | `Color?` | Grid colour. Defaults to `ColorScheme.onSurface`. |
| `borderWidth` | `double?` | Grid thickness. Defaults to 1. |
| `borderRadius` | `Radius?` | Outer corner rounding. Defaults to square. |
| `cellPadding` | `EdgeInsetsGeometry?` | Space inside a cell. Defaults to 8 by 4. |
| `headerBackground` | `Color?` | Header row fill. Defaults to `surfaceContainerHighest`. |
| `headerTextStyle` | `TextStyle?` | Header text style. Defaults to the body style. |
| `columnWidth` | `TableColumnWidth?` | Optional width policy for every column. FixedColumnWidth skips content measurement and is useful for large streaming tables. Null preserves content-sized columns. Flex widths require a bounded table width. |
| `rowStripeColor` | `Color?` | Fill for alternating rows. Defaults to none. |
| `overflow` | `TableOverflow?` | What a table wider than the available width does. Defaults to `TableOverflow.scroll`. |

| Member | Type | Description |
|---|---|---|
| `merge(TableStyle? other)` | `TableStyle` | This style, with any unset field taken from `other`, field by field. |
| `resolve(ColorScheme scheme)` | `TableStyle` | This style with every remaining default filled in. |
| `copyWith({…})` | `TableStyle` | A copy with the given fields replaced. |
| `static lerp(TableStyle? a, TableStyle? b, double t)` | `TableStyle?` | Linearly interpolates between two styles. |

### `CustomTableRow`

One row of a table, as handed to a `tableBuilder`.

| Member | Type | Description |
|---|---|---|
| `isHeader` | `bool` | Whether this is a header row: the first row of a Markdown table, or an HTML row in `<thead>` or made of `<th>` cells. |
| `fields` | `List<CustomTableField>` | The row's cells, one per column. |

### `CustomTableField`

One cell of a table, as handed to a `tableBuilder`.

| Member | Type | Description |
|---|---|---|
| `data` | `String` | The cell's text. |
| `alignment` | `TextAlign` | The cell's alignment, from the table's alignment row (or, for an HTML table, its `align` or `text-align`). Defaults to `TextAlign.left`. |

<details>
<summary><code>data</code>: more</summary>

Plain text, with its Markdown formatting removed. A row shorter than the
table is padded with empty cells, and a cell an HTML `colspan` or
`rowspan` covers is empty: the spanning cell's text is in its first slot.
The deprecated legacy parser passes the cell's Markdown source instead.

</details>

### `TableOverflow`

What a table does when it is wider than the space it is given.

| Value | Description |
|---|---|
| `scroll` | Keep every column at its content width and scroll the table sideways. The default. |
| `wrap` | Fit the table to the available width and wrap the text in its cells. |

<details>
<summary><code>wrap</code>: more</summary>

With the default column width a column shrinks toward its longest word,
so short columns stay whole. With more columns than the words allow,
words break rather than the table running off screen. A custom
`TableStyle.columnWidth` keeps its own minimum, which can leave the table
wider than the space; it is not scrolled then.

</details>
