### `BlockQuoteStyle`

How a blockquote is drawn.

Set it as `GptMarkdownStyleSheet(blockQuote: BlockQuoteStyle(…))` on the widget, or in `GptMarkdownThemeData` for the whole app. Every field is optional; an unset one falls back to the theme, then to the default.

| Field | Type | Description |
|---|---|---|
| `barWidth` | `double?` | Thickness of the bar down the side. Defaults to `3`. |
| `barColor` | `Color?` | Colour of the bar. Defaults to `ColorScheme.onSurfaceVariant`. |
| `barRadius` | `Radius?` | Rounding of the bar. Defaults to square corners. |
| `backgroundColor` | `Color?` | Fill behind the quote. Defaults to none. |
| `padding` | `EdgeInsetsGeometry?` | Space between the bar and the quoted content. Defaults to `start: 8`. |
| `margin` | `EdgeInsetsGeometry?` | Space around the whole quote. Defaults to `vertical: 2`. |
| `textStyle` | `TextStyle?` | Applied on top of the surrounding text style. Defaults to no change. |

| Member | Type | Description |
|---|---|---|
| `merge(BlockQuoteStyle? other)` | `BlockQuoteStyle` | This style, with any unset field taken from `other`. |
| `resolve(ColorScheme scheme)` | `BlockQuoteStyle` | This style with every remaining null filled in. |
| `copyWith({…})` | `BlockQuoteStyle` | A copy with the given fields replaced. |
| `static lerp(BlockQuoteStyle? a, BlockQuoteStyle? b, double t)` | `BlockQuoteStyle?` | Linearly interpolates between two blockquote styles. |

<details>
<summary><code>merge</code>: more</summary>

Per field, not per object: a style setting only `barWidth` keeps
`other`'s colour and padding.

</details>

<details>
<summary><code>resolve</code>: more</summary>

The defaults are the values the package used before blockquotes were
configurable, so an app that sets nothing sees no change.

</details>

### `blockQuoteBuilder`

Replaces the whole blockquote widget.

Reach for `styleSheet` first — it covers the bar, padding, background and
text style without giving up the default structure.

```dart
typedef BlockQuoteBuilder = Widget Function(
  BuildContext context,
  Widget content,
  BlockQuoteStyle style,
);
```
