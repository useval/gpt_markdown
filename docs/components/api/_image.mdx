### `ImageStyle`

How an image is drawn.

Set it as `GptMarkdownStyleSheet(image: ImageStyle(…))` on the widget, or in `GptMarkdownThemeData` for the whole app. Every field is optional; an unset one falls back to the theme, then to the default.

| Field | Type | Description |
|---|---|---|
| `borderRadius` | `Radius?` | Corner rounding. Defaults to square. |
| `padding` | `EdgeInsetsGeometry?` | Space around the image. Defaults to none. |
| `fit` | `BoxFit?` | How the image fills its box. Defaults to the widget default. |
| `maxWidth` | `double?` | Upper bound on width. Defaults to unbounded. |
| `maxHeight` | `double?` | Upper bound on height. Defaults to unbounded. |

| Member | Type | Description |
|---|---|---|
| `merge(ImageStyle? other)` | `ImageStyle` | This style, with any unset field taken from `other`, field by field. |
| `resolve(ColorScheme scheme)` | `ImageStyle` | This style with every remaining default filled in. |
| `copyWith({…})` | `ImageStyle` | A copy with the given fields replaced. |
| `static lerp(ImageStyle? a, ImageStyle? b, double t)` | `ImageStyle?` | Linearly interpolates between two styles. |

### `onImageTap`

Called with the image URL when an image is tapped.

An image that is a link's label — `[![alt](src)](url)` — follows the
link instead, through `onLinkTap` with the link's URL and the alt text.
Without an `onLinkTap` it falls back to this.

```dart
void Function(String url)? onImageTap
```
